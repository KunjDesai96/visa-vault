# Contributing to Visa Vault

Thanks for your interest in contributing! 🎉

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Run `npm run lint` to check for issues
5. Commit using conventional commits: `feat:`, `fix:`, `docs:`, `chore:`
6. Push and open a Pull Request

## Good First Issues

Look for issues labeled `good first issue` or `documentation`.

## Code Style

- TypeScript everywhere
- Tailwind for styling
- Keep components small and focused

## Questions?

Open a GitHub Discussion or drop a comment on the issue you're working on.
